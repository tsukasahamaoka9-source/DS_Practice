# 2026-08-08 Paper Digest

## OrthoDiffusion: A Generalizable Multi-Task Diffusion Foundation Model for Musculoskeletal MRI Interpretation

- 著者: Tian Lan, Lei Xu, Zimu Yuan, Shanggui Liu, Jiajun Liu, Jiaxin Liu, Weilai Xiang, Hongyu Yang, Dong Jiang, Jianxin Yin, Dingyu Wang（人民大学・北京大学第三医院運動医学研究所・北京航空航天大学など）
- - 発表: arXiv, 2026年2月24日 (v1)
  - - 分野: cs.CV / cs.AI（筋骨格系MRI・拡散モデルによる自己教師あり表現学習）
    - - リンク: https://arxiv.org/abs/2602.20752 （HTML版: https://arxiv.org/html/2602.20752v1）
     
      - ### 背景・課題
     
      - 筋骨格系疾患（膝・足首・肩の靭帯損傷や半月板断裂など）は世界で約17.1億人が抱える主要な障害原因であり、MRIが標準的な非侵襲診断手段となっている。しかし読影は難しい。単一の検査内に複数の異常が併存しうること、解剖構造が複雑な3次元であること、矢状面・冠状面・軸位面という複数の撮像平面の情報を統合して初めて正確な診断ができることが要因である。既存の深層学習手法の多くは、ACL（前十字靭帯）損傷検出のように単一関節・単一疾患に特化して学習されており、施設・スキャナー・患者集団が変わると汎化しにくいという弱点があった。
     
      - ### 提案手法の概要
     
      - - OrthoDiffusion: 矢状面・冠状面・軸位面それぞれに独立な3D拡散モデル（3D U-Netによるノイズ予測器）を用意し、15,948件のラベルなし膝MRI検査で自己教師あり事前学習する。ラベルを一切使わず、ノイズ除去（denoising）というタスクを解く過程で解剖学的に意味のある特徴が学習される点がポイント。
        - - 中間表現の再利用: 拡散モデルの学習後、生成そのものではなく、ノイズ除去過程の特定のtimestep・特定のネットワーク層（bottleneck）から取り出した中間特徴量を下流タスクに転用する（著者らの先行研究DDAEと同じ思想）。分類タスクにはプーリング後に軽量な分類ヘッド、セグメンテーションタスクには軽量なセグメンテーションヘッドを載せるだけで、拡散モデル本体は共通のまま複数タスクに使い回せる。
          - - 平面間融合: 3平面（矢状面・冠状面・軸位面）の特徴を統合する方法として、単純な特徴連結（concatenation、数値的に最良）に加え、疾患ごとにどの平面をどれだけ重視するかを患者ごとに動的に決める「Multi-plane Adaptive Expert (MPAE)」ゲーティング機構も提案。後者はSankey図で可視化すると、十字靭帯損傷は矢状面、側副靭帯損傷は冠状面を重視するなど、臨床的な読影パターンと一致する重みが学習されていたと報告している。
            - - 他関節への転移: 膝MRIのみで事前学習した拡散バックボーンを、そのまま足首・肩の診断タスクにも軽い微調整だけで適用し、関節ごとの再事前学習を不要にしている。
              - - 電子カルテ（EHR）の構造化データとMRI特徴を融合する実験も行っているが、改善幅は小さいと報告されている。
               
                - ### 主な結果
               
                - 30,653件のMRI検査・9施設からなる大規模マルチセンターデータで評価。
               
                - - 膝の8疾患診断（ACL損傷・PCL損傷・内側/外側半月板断裂・内側/外側側副靭帯損傷・膝蓋骨脱臼・関節液貯留）で、最良設定（fine-tuning、timestep/blockを最適化）のマクロ平均AUROCは0.908。3D-Unet（0.826）・3D-ResNet-18（0.832）といった教師ありベースラインを一貫して上回った。
                  - - 11の解剖構造（大腿骨・脛骨・軟骨・半月板・十字靭帯など）のセグメンテーションでも、3D-UnetやUNETRを上回るDiceスコアを達成。
                    - - ラベル効率が最大の主張点: 訓練ラベルを10%まで減らしても、CNNベースラインに比べて性能劣化が著しく小さい（label-efficient）。磁場強度（1.5T/3.0T）が異なる施設間でも頑健性を保持。
                      - - 膝のみで事前学習したバックボーンを足首（4タスク）・肩（7タスク）に転移しても、それぞれをゼロから学習したCNNベースラインを上回った。関節間の解剖学的類似度が高いほど（膝→足首）転移の恩恵が大きいと報告。
                       
                        - ### Kaggleでの実践への示唆
                       
                        - 直近2日間（08-06, 08-07）のDaily_Kaggle_Reviewで扱った「RSNA Knee Abnormality Detection」は、まさにこの論文と同じ膝MRI・異常検出タスクであり、正解ラベルがごく少数（58件程度）という極小データ設定でDINOv2（対照学習・自己蒸留ベースの視覚基盤モデル）を凍結特徴抽出器として使う手法が紹介されていた。本論文は同じ「自己教師あり事前学習→凍結/軽微調整の下流ヘッド」という戦略を、DINOv2系の対照学習ではなく拡散モデルのノイズ除去過程の中間表現という別の切り口で実現しており、しかも同一の膝MRIドメインで10%ラベルでも高精度という定量的な裏付けがある点が実務上重要である。
                       
                        - 具体的な応用仮説としては、(1) 既存notebookのDINOv2特徴に加えて、Stable Diffusion系の事前学習済み拡散モデル（医療画像専用でなくても、denoising過程の中間活性化）を第二の特徴抽出器として追加し、アンサンブルの多様性を増やす、(2) 本論文のように「どのtimestep・どの層が下流タスクに効くか」をvalidationで探索するという発想を、他の凍結バックボーン（DINOv2含む）の層選択にも応用する、(3) RSNAコンペのように矢状面・冠状面など複数シーケンス（撮像方向）が与えられる場合、単純結合ではなく疾患ラベルごとに動的な重み付け（MPAE的なゲーティング）を試す、という3点が考えられる。ただしOrthoDiffusion自体は膝MRI以外の一般公開モデルではなく（重み非公開の可能性が高い）、そのままKaggle環境に持ち込むのは難しいため、着想の転用が中心になる。
