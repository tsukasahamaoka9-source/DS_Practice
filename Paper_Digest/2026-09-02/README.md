# 2026-09-02 Paper Digest

## Differentiable optimization layers enhance GNN-based mitosis detection

- **著者**: Haishan Zhang（東京大学 新領域創成科学研究科）, Dai Hai Nguyen（筑波大学）, Koji Tsuda（東京大学 / 理研AIP / 物質・材料研究機構）
- **発表**: Scientific Reports, Vol.13, 14306, 2023年8月31日
- **分野**: 細胞追跡・分裂（mitosis）検出／グラフニューラルネットワーク／微分可能最適化
- **リンク**: https://doi.org/10.1038/s41598-023-41562-y （全文: https://pmc.ncbi.nlm.nih.gov/articles/PMC10471751/ ／ コード: https://github.com/95-HaishanZHANG/GNN-DOL ）
- **選定理由**: 直近の Biohub レビュー（2026-08-30 / 08-31 / 09-01）で繰り返し「**Division Jaccard がほぼ機能していない**（validation実測 0.1667、Division FP = 0 = 保守的すぎる）」がボトルネックとして挙がっている。本論文は「分裂という生物学的制約を、後処理ではなく**モデルの中**に入れる」ことでまさにその recall を上げた研究。

## 1. 背景・課題

細胞追跡が一般の物体追跡と決定的に違うのは、**追跡対象が途中で2つに分裂する**点にある。従来の分裂検出は2系統に分かれる。

- **形状ベース（shape-based）**: 各フレームを独立に見て、「球形で輪郭が明るい」という分裂直前の特徴的な形をした細胞を検出器で拾う。**娘細胞が特定できない**うえ、その「特徴的な形」は培地や顕微鏡の種類に依存するので汎化しにくい。
- **リンクベース（link-based）**: 全細胞を検出し、隣接フレーム間のリンクを予測して、**出ていくリンクが2本ある細胞を親と判定する**。娘細胞まで分かるのが利点。

リンクベースの中でも、Jugらの数理計画法による手法は「1細胞は最大2細胞にしか対応しない」という生物学的制約を明示的に課せた。一方、より新しい Ben-Haim & Raviv のGNN手法は精度で上回ったが、**制約を一切課していない**。制約を課さないと、モデルは「1つの親から3つの娘」のような生物学的にありえない対応を出しうるし、逆にそれを避けるために保守的になって取りこぼす。

さらに深刻なのが**データ量の問題**。一般の画像認識では「大量のデータからルールを自動で学ばせる」のが定石だが、科学画像のデータ量は桁違いに少ない。特に**「1フレーム内に分裂が2件以上同時に起きる」ケースは訓練データにほとんど現れない**ため、純粋なデータ駆動では学習しようがない。著者らはここに「既知の制約を明示的に埋め込む」動機を見出している。

## 2. 提案手法の概要 — GNN-DOL

**微分可能最適化層（Differentiable Optimization Layer, DOL）** を使う。これは Amos & Kolter が提案した「**数理計画問題そのものをニューラルネットの1層として使う**」技術で、目的関数の係数を入力、最適解を出力とする層。逆伝播はKKT条件と陰関数定理から「解の係数に関する微分」を解析的に求めることで通す。普通の層と違い、**出力にハード制約を強制できる**のが最大の利点。

パイプラインは3段:

1. **U-Netによる前処理**: 画像から細胞重心のセグメンテーションマップを出す。同時に、収縮側（contraction）の中間層から各細胞パッチ（50×50）の形状特徴ベクトルを抜き出す。
2. **GNN（上流ブロック）**: フレーム *t* と *t+1* それぞれについて、細胞をノード、**各細胞を最近傍2つと結んだ辺**をエッジとする「セルグラフ」を作る。ノードには形状特徴、エッジには位置特徴を持たせ、メッセージパッシングで両方を相互に更新する。更新後の特徴の内積から、**ペアワイズ類似度行列 Q**（サイズ mm′ × mm′）を作る。ここで「ノード同士の類似」だけでなく「**エッジ同士の類似**」も Q に入っている点が重要 — つまり「細胞Aと細胞Bの位置関係」が次フレームの「細胞A′と細胞B′の位置関係」と似ているか、という**二次の（構造的な）情報**を扱っている。
3. **DOL（下流ブロック）**: Q を係数とする**二次計画問題（quadratic program）** を解いて、対応行列 Z を出力する。

```
z* = argmin  (1/2) zᵀ Q z
     s.t.    A₁z = 1        ← t+1の各細胞は、tのちょうど1細胞に対応する（娘は必ず親を持つ）
             A₂z ≤ 2        ← tの各細胞は、t+1の高々2細胞にしか対応しない（分裂は2分裂まで）
             0 ≤ z ≤ 1
```

この **`A₂z ≤ 2` が「分裂は最大2つまで」という生物学的制約そのもの**。最適解 z* を列方向の最大値で二値化し、**t+1の2細胞と繋がった細胞を親（=分裂イベント）と判定する**。

実装はPyTorch + neural-scs（訓練時）、CVXPY（推論時）。損失は重み付きバイナリクロスエントロピー、Adam（lr=1e-4）。訓練を高速化するため、訓練時のみ1グラフあたりの細胞数を30個に削っている（娘細胞とその親は必ず含め、残りをランダムに埋める。**テスト時は全細胞を使う**）。

**比較用の Naive-GNN** も作られている: GNNまでは同一で、DOLの代わりにMLPで対応行列を直接出す（制約なし）。DOLの有無だけを切り分けるための対照実験。

## 3. 主な結果

データセットは公開の **C2C12**（マウス筋芽細胞、4つの培地条件 = FGF2 / BMP2 / FGF2+BMP2 / 対照。各1013フレーム、1392×1040px、1.3µm/px、隣接フレーム間の細胞移動は平均約6px）。各条件で3配列を訓練、1配列をテストに使う。

**分裂イベント検出のF1スコア**:

| 手法 | FGF2 | BMP2 | FGF2+BMP2 | Control |
|---|---|---|---|---|
| **GNN-DOL** | **0.869** | **0.815** | **0.792** | **0.811** |
| GNN-B&R（制約なしGNN, SOTA） | 0.653 | 0.646 | 0.615 | 0.688 |
| MPM | 0.647 | 0.618 | 0.596 | 0.730 |
| Naive-GNN（DOLをMLPに置換） | 0.515 | 0.591 | 0.589 | 0.473 |

**この表の読み方で最も重要なのは precision と recall の内訳**:

| | GNN-DOL | GNN-B&R |
|---|---|---|
| Precision | 0.940〜0.957 | 0.870〜0.956 |
| Recall | **0.679〜0.808** | **0.476〜0.540** |

つまり **precision はほぼ横並びで、差はまるごと recall から来ている**。著者らの言葉では、制約なしGNNは「検出しにくい分裂イベントを取りこぼしやすい」。

さらに Fig.4 の分析では、**1フレームに分裂が2件以上あるケースで GNN-B&R が特に大きく崩れる**ことが示されている。理由は明快で、多重分裂は訓練データに稀にしか現れないから、データ駆動では学べない。制約を明示的に入れた GNN-DOL はそこで効く。

**代償**: 二次計画を解くぶん、1フレームペアあたりの計算時間が Naive-GNN の**約3倍**。

**著者自身が挙げる限界**: U-NetとGNN-DOLが分離しており、**U-Netの検出ミスは後段で永久に修正できない**（end-to-end化が今後の課題）。

> 精読範囲の断り: 本文（Introduction / Method / Results / Conclusion）と全表は読んだが、**Supplementary Information（詳細アルゴリズム）は未読**。DOLの実装細部（QPソルバーの収束条件、微分の数値安定性の扱い）については確認できていない。

## 4. Kaggleでの実践への示唆（Biohub - Cell Tracking During Development）

現行の公開notebook群（0.926〜0.934帯）の構造は、この論文の「Naive-GNN + 後付けの制約」に極めて近い。

```
現行Biohubパイプライン:
  TemporalUNet3D（検出） → Node Transformer（ペアワイズにリンク確率を推定） → ILP（制約を課して解く） → 後処理（safe division / gap closing）
                              ↑ここは制約を知らない            ↑ここで初めて制約が入る
```

**論文の主張をこの図に当てはめると、問題は「制約が最後にしか入らないこと」ではなく、「制約が上流のパラメータに一切フィードバックされないこと」**。GNN-DOL の核心は、DOLを通した逆伝播が**上流GNNの重みを望ましい方向に動かす**点にある（著者らも "the use of DOL affected the upstream parameters of GNN in a favorable manner" と明記）。現行パイプラインの Node Transformer は「2細胞のペアが繋がるか」を独立に学習しており、「この細胞から3本出てはいけない」という事実を学習時に一度も見ていない。ILPが後で辻褄を合わせてくれるので、**確率の質そのものが競合を考慮していない**。

そして症状が完全に一致している。09-01 のレビューで観測されたのは **Division Jaccard = 0.1667 / Division FP = 0** — すなわち**precisionは完璧だがrecallが壊滅**という状態で、これは論文の GNN-B&R の失敗モード（precision 0.87〜0.96 / recall 0.48〜0.54）とまったく同じ形をしている。「保守的すぎて取りこぼす」という同じ病気に、論文は「制約を学習に組み込む」という処方を出している。

もう一点、**Q行列にエッジ同士の類似度を入れている設計**が、08-05 に読んだ HOCT（エッジ中心Transformer）の主張と独立に同じ結論に到達している。「隣り合う細胞同士の位置関係が保存されているか」という二次の情報は、細胞のように見た目が似ている対象では**外見特徴より強い手がかり**になる。現行のNode Transformerはここを使っていない。

ただし冷静に見るべき点として、**C2C12は2Dで細胞移動が平均6px、Biohubはゼブラフィッシュ胚の3D+時間で密度もはるかに高い**。QPの変数数は mm′ に比例するので、Biohubの規模（1フレーム数百〜数千ノード）にそのまま持ち込むと計算量が破綻する可能性が高い。**論文の手法をそのまま移植する話ではなく、「制約を学習に返す」という設計思想を、実行時間9時間の制約下で成立する形に落とす**のが実務的な読み方になる。

## 5. 実装可能な仮説（→ `research/backlog.md` 起こし用）

### 仮説1: 分裂制約を「損失」として Node Transformer の学習に返す（DOLの安価な代用）

- **手法**: DOL（二次計画層）は推論コストが3倍になるため導入せず、代わりに**制約違反にペナルティを課す補助損失**を Node Transformer の学習に足す。具体的には、あるノード *i* から t+1 に出る全リンク確率の和 `Σ_j p(i→j)` に対して `max(0, Σ_j p(i→j) − 2)²` を加算する（= `A₂z ≤ 2` のソフト版）。同様に t+1 側は `(Σ_i p(i→j) − 1)²`（= `A₁z = 1` のソフト版）。ラグランジュ緩和として実装すれば追加コストはほぼゼロ。
- **期待インパクト**: Division Jaccard の recall 改善。現状 div_j ≈ 0.0625〜0.1667 が 0.3 まで上がれば、合成スコアの分裂枠（重み約0.1〜0.15）で **+0.02〜0.03 相当**。Edge Jaccard 側は制約が正しい方向なので劣化しにくいはず（要検証）。
- **工数**: 中（学習コードに損失項を1つ足す + 再学習。既存重みを使う推論のみのnotebookでは不可能で、学習から回す必要がある点が最大のコスト）。
- **出典**: 本論文 Eq.(1) の制約 `A₁z = 1, A₂z ≤ 2` と、Table 2 の recall 差（0.48→0.68〜0.81）。

### 仮説2: エッジ同士の二次類似度を、ILPのコスト行列に加算する（学習不要・推論のみ）

- **手法**: 現行のエッジコストは「2細胞ペアの確信度」という一次の量。これに、**近傍構造の保存度**を表す二次の項を足す。実装は、各ノードについて空間的最近傍k個（論文はk=2）を取り、リンク候補 (i→k) と (j→l) について「iとjの相対ベクトル」と「kとlの相対ベクトル」の差のノルムを計算し、小さいほどコストを下げる。論文の Q 行列のエッジ成分と同じ発想を、**学習せずに幾何量として直接計算する**。
- **期待インパクト**: 密集領域での誤接続（Edge FP）の削減。09-01 のエラー分解で「誤接続」が支配的な成分なら効くし、そうでなければ効かない — **先に `decompose_errors` の内訳を見てから着手すべき**。
- **工数**: 小〜中（推論後処理のみ。ILPのコスト行列を組む箇所に20〜50行。学習不要なので既存の高スコアnotebookにそのまま乗る）。
- **出典**: 本論文 Q行列のエッジ成分の定義（`Q_αβ = ē_ij (ē′_kl)ᵀ` for (i,j)∈E, (k,l)∈E′）、および HOCT（[arXiv:2607.11754](https://arxiv.org/abs/2607.11754)）のエッジ中心設計。

### 仮説3: 「多重分裂フレーム」を層化した検証セットを作る

- **手法**: 論文 Fig.4 の「1フレームに分裂が2件以上あると制約なし手法は大きく崩れる」という知見を検証設計に反映する。現行の `VALIDATOR_N_PER_TYPE = 2` に加えて、**分裂イベント数でフレームを層化**し、「分裂0件 / 1件 / 2件以上」の3層でそれぞれ Division Jaccard を出す。
- **期待インパクト**: スコア自体は上がらないが、**どの層で落としているかが分かる**。仮に「2件以上の層で全滅」なら仮説1の期待効果は大きく、「1件の層ですでに落としている」なら原因は制約でなく検出側（`SAFE_DIV` の距離帯）にある。**仮説1に工数を投じる前に、これを先にやるべき**。
- **工数**: 小（検証スクリプトの集計を層別にするだけ。半日以内）。
- **出典**: 本論文 Fig.4a の分裂イベント数別マーカー分析、および Conclusion の "GNN-DOL was particularly accurate, when there are multiple mitosis events in an image."

## 6. まとめ

「深層学習は大量データからルールを自動発見する」という定石が、**科学データの少なさの前では逆転する**ことを、対照実験（Naive-GNN vs GNN-DOL）で切り分けて示した論文。精度差がまるごと recall から来ていること、そして稀なケース（多重分裂）ほど制約埋め込みの効果が大きいことが、Biohub の現状の症状（分裂検出が保守的すぎて取りこぼす）と正確に重なる。

Biohubへの持ち込みは、DOLそのものより **「制約を上流の学習に返す」という設計思想**の方が実用的。ただし着手順は 仮説3（層別検証で原因を特定）→ 仮説2（学習不要で安い）→ 仮説1（再学習が必要で高い）とするのが合理的。
