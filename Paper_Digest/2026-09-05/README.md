## Learning co-plane attention across MRI sequences for diagnosing twelve types of knee abnormalities

- **著者**: Zelin Qiu, Zhuoyao Xie, Huangjing Lin, Yanwen Li, Qiang Ye, Menghong Wang, Shisi Li, Yinghua Zhao, …, Hao Chen（香港科技大学 / 南方医科大学第三附属病院 ほか計5施設）
- **発表**: Nature Communications, Vol.15, Article 7637, 2024年9月2日
- **分野**: 医用画像（膝MRIのマルチシーケンス・マルチプレーン12所見マルチラベル分類）
- **リンク**: [DOI: 10.1038/s41467-024-51888-4](https://doi.org/10.1038/s41467-024-51888-4) ／ [全文(PMC)](https://pmc.ncbi.nlm.nih.gov/articles/PMC11368947/) ／ [コード: zqiuak/CoPAS](https://github.com/zqiuak/CoPAS)

## 1. 背景・課題

膝MRIの読影は、複数の撮像面（矢状断・冠状断・軸位断）と複数のコントラスト（PDW / T1W / T2W）を**行き来しながら**行う作業であり、時間がかかるうえ経験の差が大きく出る。従来の自動化研究——代表例が MRNet（Bien et al., 2018）——は、①**所見を2〜3種類（半月板断裂・ACL断裂など）に絞る**、②**撮像面ごとに独立したネットワークを走らせ、最後に max pooling や concat で単純に統合する**、という二つの制約を抱えていた。

しかし臨床の実像は「複数の所見が同時に起きる」であり、しかも**所見ごとに最適な撮像面が違う**（半月板断裂は矢状断、内側・外側側副靭帯は冠状断、といった読影の定石がある）。所見を絞れば実用にならず、撮像面を対等に平均すれば「その所見にとって役に立たない面のノイズ」を等しく混ぜてしまう。加えて膝MRIは**スライス厚が面内解像度に比べて大幅に粗い（異方性）**ため、単一ボリュームを補間して等方化しても情報は増えない。

本論文は、5施設・1,748症例・12所見という（発表時点で）最大規模の多施設マルチシーケンス膝MRIデータセットを構築したうえで、この「面と所見の対応関係」をモデルの内部構造として明示的に持たせた **CoPAS（Co-Plane Attention across MRI Sequences）** を提案している。

## 2. 提案手法の概要

### 2.1 前処理：セグメンテーションでROIを決め、**回転で疑似的な別断面を作る**

1. **U-Netで半月板を粗くセグメンテーション**し、その重心を膝の基準点として画像をクロップ。位置合わせが目的なので精密なマスクは不要、という割り切り。
2. **ボリューム回転（re-slicing）**。矢状断ボリュームは `224 × 224 × 24`（面内は高解像度、スライス方向は24枚しかない）。これを90度回転すると `24 × 224 × 224` の「冠状断っぽいボリューム」になる。**同じデータだが、軸の割り当てが違う**。この操作で元の5ボリューム（PDW矢状/冠状/軸位、冠状T1W、矢状T2W）から**計11ボリューム**（PDW 9本 + T1W + T2W）を生成する。
   - 補間で異方性を埋めるのではなく、**他の面で高解像度に撮られた実データを持ち込む**というのが要点。補間は情報量を増やさないが、直交する別スキャンは本当に新しい情報を持っている。

### 2.2 3ブランチ構成とクロスプレーン・アテンション

矢状・冠状・軸位に対応する3つのブランチを用意。各ブランチで:

- エンコーダは **ResNet3D-18**。ブランチ内の全ボリュームで**重みを共有**する（主ボリューム基準で重みが更新されるので、その面に特化した特徴抽出器になる）。
- 最終プーリングを**最後の2次元だけ**に掛け、`C×D×H×W → D×C` に整形する。つまり**スライスの並び順を保ったまま、スライスごとの埋め込み列**にする（Transformerに入れるトークン列を作るのと同じ発想）。
- **クロスプレーン・アテンション**: 主ボリュームの特徴から Query、回転で作った2本の疑似ボリュームから Key/Value を作り、2本分のアテンション出力を足し合わせ、正規化・線形層を通したうえで**主特徴に残差として加算**する。
  数式は標準的な scaled dot-product attention（`Softmax(QKᵀ/√d)V`）の2本和。
→ 「スライス間の粗さで落ちた情報を、直交断面から拾ってくる」機構。

### 2.3 コプレーン・クロスシーケンス・アテンション（PDW × T1W/T2W）

PDW（プロトン密度強調）は病変の描出に優れ、T1W/T2W は**解剖構造の見取り図**として優れる、という役割の違いを利用する。ここでは単純な加算・連結ではなく、**2シーケンス間のコントラストからチャンネル方向のアテンション係数を作り、特徴を再重み付けする**（フィルタとして使う）。クロスプレーン側と違い、エンコーダは**共有せず個別に学習**する。

### 2.4 プレーン認識確率行列（plane-aware probability matrix）— 本論文の肝

3つのブランチはそれぞれ12所見の予測ベクトルを出す。これを平均や連結で潰すのではなく、**3本のベクトルの外積で3階の確率行列**を作る。要素 `x_{i,j,k}` は「矢状断のi番目所見 × 冠状断のj番目 × 軸位のk番目」の積。

- **対角成分**（`i=j=k`）は「3面が同時にその所見を支持する」joint probability であり、これを**ベース予測**とする。
- 非対角成分は**所見どうしの相関**（例: 関節液貯留と嚢腫は信号が似る）と**所見×撮像面の相関**を同時に含む。
- ここに **12チャンネルの畳み込み**を掛けて位置依存のパターンを抽出し、**SENet流に squeeze → 線形変換**でベース予測に掛ける重みベクトルを生成、対角ベクトルをスケーリングして最終予測とする。

つまり **「所見ごとに、どの面をどれだけ信じるか」を固定の定数ではなく入力依存の学習パラメータとして持つ**。これが本論文とRSNAコンペ公開notebookの決定的な差である（後述）。

### 2.5 損失

最終予測には **Focal Loss**（難サンプル重視）、3ブランチそれぞれの予測には **BCE** を掛け、係数 α で balance する。ブランチ出力への直接教師＝deep supervision であり、「各面が単独でも所見を当てられる」ことを強制してから統合している。

判定しきい値は **F1最大化**で決めている（AUCは順位のみを見るので、ACC/F1報告時にのみ効く）。

## 3. 主な結果

| 項目 | 数値 |
|---|---|
| 内部テスト（センターA, n=220）平均 AUC-ROC | **0.812** |
| 既存手法比 | MRNet / MPFuseNet / ELNet に対し **12所見中8所見で上回る**（MCL・EFFUはMRNet、ACLはMPFuseNetが上） |
| 外部テスト（センターB–E, n=645, シーケンス構成が異なる） | **0.721 / 0.726**（内部から**約0.09の低下**） |
| 骨挫傷（CONT）の外部AUC | 0.821 → **0.698**（T1W/T2W欠落の影響が最大） |
| 平均ACC | モデル **0.78** / 若手放射線科医 0.65 / 熟練 0.80 |
| モデル出力を提示した場合の読影医の精度 | 0.73 → **0.79**（p < 0.001, 6名全員で有意に改善） |
| データ | 5施設 1,748例（内部1,103 = 773/110/220、外部645）、ラベルは**関節鏡所見とMRIの併用**で付与 |

補足すると:

- **強いのは空間的に複雑な所見**。十字靭帯（ACL/PCL）や側副靭帯（MCL/LCL）のように「複数スライスにまたがって走行する構造」で熟練医を上回った。これはクロスプレーン・アテンションの効き方として理屈が通っている。
- **弱いのはマルチタスクの負の転移**。単一タスクのMRNetが EFFU（関節液貯留）や MCL で勝っている。著者自身が「関節液と嚢腫は信号増強が似ており、他タスクに引きずられる」と ablation（単一タスク版との比較）で確認したと述べている。一方で**症例数が最も少ないPR（膝蓋支帯損傷）ではマルチタスクが最良**——所見間の隠れた相関が小データを補う、という逆向きの効果も出ている。
- **解釈性**: EigenCAM / Grad-CAM++ で見た「所見×撮像面の活性パターン」は、放射線科医が申告した読影の定石と**CONTとPLICAを除いて高い正相関**を示した。モデルが臨床の暗黙知と同じ優先順位を独立に獲得したことになる。
- **限界（著者申告）**: ①シーケンスごとに別エンコーダを持つためパラメータが多く、少データでは過学習しやすい。②3面すべての撮像を要求するため、実運用でのデータ要件が厳しい。③完全教師あり（関節鏡ラベルは高コスト）。

## 4. Kaggleでの実践への示唆（RSNA Knee Abnormality Detection）

直近の日次レビュー（2026-08-31 / 09-01 / 09-02 / 09-03）で扱った RSNA Knee の公開notebook上位帯（LB 0.935〜0.936）と本論文を並べると、**同じ問題に対して両者がまったく別の場所に労力を払っている**ことが見えてくる。

**公開notebookの現状**は、4本の強力な2Dバックボーン（DINOv2 / RadImageNet / CoAtNet / DINOsaur）をスライス単位で走らせ、**順位空間で融合**し、`_a5_target_w` という**12個の手調整スカラー**で所見別に重み付けする、という構成だった。この12個の重みは「macro-AUC ＝ 12個の独立問題」という指標構造を正しく反映しているが、2026-09-03のレビューで指摘した通り**導出根拠が notebook 内に一切書かれておらず、public LB で手調整した可能性が高い**（12自由度をLBに合わせるのは、LBを検証セットとして消費する行為）。

本論文はまさにその12個を、**プレーン認識確率行列という微分可能な機構で学習させている**。しかも学習された重みが、放射線科医の読影の定石（半月板＝矢状断、側副靭帯＝冠状断）と事後的に一致することまで検証している。つまりコンペ側の「LBで12個を振る」は、**学習可能なうえに臨床事前知識で検算できるパラメータを、最も信頼できない情報源（public LB）で決めている**ことになる。ここが最大の乖離点であり、最も投資対効果の高い改善余地だと考える。

もう一点、**入力の作り方**にも直接効く示唆がある。RSNAの上位notebookは `CROP_MM = 130.0` で DICOM の PixelSpacing を使った物理単位クロップまでは徹底しているが、**スライス厚の異方性**（膝MRIでは面内0.3–0.5mm前後に対しスライス厚3–4mm、Biohubのz軸4倍粗い問題と構造的に同じ）に対する手当ては見当たらない。本論文の「回転して疑似的な別断面を作り、直交スキャンからアテンションで情報を借りる」という手は、**新規データも追加学習データも一切要らず、既に配布されている3面のシリーズを組み替えるだけ**で実装できる。Biohubで既に身につけている「距離はµm/mmの物理単位で扱う」「軸ごとの解像度差を無視しない」という作法の、自然な次の一歩にあたる。

最後に、本論文の**負の転移の指摘**は、公開notebookが所見別重みを下げる形で経験的に対処している現象（Fracture / Baker's の重みを 0.38 に落としている）に、**理由を与えてくれる**。「弱いから重みを下げる」という受け身の対処ではなく、「その所見は他タスクに引きずられているので単一タスクヘッドに逃がす」という能動的な設計判断に置き換えられる。

### 実装可能な仮説

> 形式: {手法 / 期待インパクト / 工数 / 出典}。そのまま `research/backlog.md` に起こせる粒度で書く。

**H1. 所見別融合重み `_a5_target_w` を、LB手調整から「プレーン認識確率行列」の学習に置き換える（最優先）**

- **手法**: 現行4armの出力を「面ごと」ではなく既に混ざった状態で持っているので、まずは中間段階として **面別（sag / cor / ax）に予測ベクトルを分離**し、3本の12次元ベクトルの外積で 12×12×12 行列を作る。対角＝ベース予測、そこに 12ch conv + squeeze（SENet型）で重みを学習させる小さなヘッドを乗せる。学習データはレポート由来のLLMソフトラベル4,349件のOOF、検証は本物ラベル58件のホールドアウト（**学習には一切使わない**規律を維持）。
- **期待インパクト**: 中〜大。macro-AUC は12所見の単純平均なので、稀少所見（Fracture / Baker's）1つの改善が全体の 1/12 = 8.3% を動かす。現行の手調整重みが public LB に過剰適合しているなら、**private LB でのシェイクダウン防止**という下振れ回避の価値がさらに大きい。
- **工数**: 中（2〜3日）。既存の4arm推論結果を面別に出し直す改修が主。ヘッド自体は数十行。
- **出典**: 本論文 §Methods "Plane-aware feature integration with abnormality probability matrix" ／ [CoPAS実装](https://github.com/zqiuak/CoPAS) ／ 対比: [RSNA Knee: Full 4-arm ensemble v55](https://www.kaggle.com/code/nishantkharga/rsna-knee-full-4-arm-ensemble-v55)

**H2. クロスプレーン・ボリューム回転を入力構築に導入する（低リスク・低コスト）**

- **手法**: 各症例の矢状断・冠状断・軸位断シリーズを、それぞれ90度回転（re-slice）して疑似的な別断面ボリュームを生成し、既存バックボーンへの**追加入力チャンネル / 追加TTAビュー**として与える。まずはフルのクロスアテンションを実装せず、**「回転ビューを足したTTA」だけ**で効果を測るのが安全（既存パイプラインをほぼ触らない）。効いたらアテンション統合に進む。
- **期待インパクト**: 小〜中。スライス厚方向の情報欠落が支配的な所見（十字靭帯・側副靭帯のように走行が斜めの構造）で伸びるはず。本論文が熟練医を上回ったのがまさにこれらの所見であることが傍証になる。**新規データ不要**なのが最大の利点。
- **工数**: 小（半日〜1日）。`np.rot90` / `np.transpose` と、DICOM の `SliceThickness` / `PixelSpacing` を見た軸整合の確認だけ。
- **出典**: 本論文 §Methods "Pre-processing with image cropping and volume rotation"

**H3. 負の転移が起きている所見を特定し、単一タスクヘッドに逃がす**

- **手法**: 現行の12出力を1モデルで出している部分について、**所見ペアごとの予測相関**を OOF 上で測り、「信号特性が似ていて互いに引っ張り合っている」ペアを洗い出す（本論文が挙げた EFFU × CYST が典型）。該当する所見だけ**専用の単一タスクヘッド（もしくは別モデル）**を用意し、融合段で置き換える。効果測定は所見別AUCの差分で行う。
- **期待インパクト**: 小〜中。本論文では MRNet（単一タスク）が MCL・EFFU で CoPAS を上回っており、**「マルチタスクが常に勝つわけではない」ことが実測されている**。macro平均なので、負けている2〜3所見だけを救う施策は費用対効果が高い。
- **工数**: 中（診断だけなら1日、専用ヘッドの学習まで含めて3〜4日）。
- **出典**: 本論文 §Discussion（"single-task methods, such as the MRNet, may outperform our approach in some tasks" とし、単一タスク版とのablationで確認したと記述）
