- **2026-08-21**（Biohub - Track Your Cells Development, Public 0.916）: 分裂修復を強めるとFPが増えるので、

- **2026-08-19**（Biohub 0.902）: モデルを一切触らず後処理パラメータ5個だけを校正して0.902。
  つまり**上位帯の差は、ほぼ全部が「割当のあと」で作られている**。

3本とも、**割当問題そのものが分裂を表現できない**という構造的欠陥を、後処理のパッチで塞いでいる。
本論文は、その欠陥を**割当問題の定式化のレベルで**直す。しかも「後から間違いを取り消せる」枠組み（MHT）と
組み合わせるので、08-21で見た「増やす側とブレーキを別モデルで持つ」という設計より原理的に上位互換になりうる。

なお、Biohubの公式指標は**分裂イベントの正誤を明示的に含む複合スコア**なので、
分裂を1件も取れていない現状は、スコア上の伸びしろがそのまま残っている状態と言える。

過去の細胞追跡ダイジェスト（2026-08-05 HOCT / 2026-08-12 Cell-TRACTR）とは重複しない。
HOCTとCell-TRACTRはどちらも「検出とリンクを1つのニューラルネットに寄せる」方向だったが、
本論文は逆に**ニューラルネットは既存のまま一切再学習せず、その外側の確率的な割当・仮説管理だけを作り直す**方向で、
Kaggleの推論時間制約（T4 x2 で17〜23分）との相性がむしろ良い。

### 背景・課題

細胞追跡の評価には2種類の指標がある。1つは**技術的指標**（フレーム単位の検出精度、リンクの正誤など、
一般的な多物体追跡と同じ発想の指標）。もう1つは**生物学的指標**（系統樹＝lineage treeが正しく再構成できているか、
細胞周期の長さの分布が合っているか）。

著者らの主張の出発点は、**この2つが乖離する**という観察である。既存手法は技術的指標を最適化するよう設計されており、
実際その値はほぼ飽和している（本論文の手法とベースラインの差は「ほぼノイズ」とまで書かれている）。
しかし生物学的指標で見ると大差がつく。理由は単純で、**系統樹の中で1回の分裂の誤りが起きると、
その下流の枝が丸ごと壊れる**からである。フレーム単位のリンク1本を間違えたのと、
分裂を1つ取り違えたのとでは、生物学的な被害の大きさが桁違いになる。にもかかわらず、
技術的指標は両者をほぼ同じ重さで数える。

技術的な原因は2つある。

1. **1対1割当は分裂を表現できない。** ハンガリー法やその発展形（Murty法）は、
   コスト行列の各行・各列に1つずつしか割当を許さない。分裂とは「1つの親に2つの娘が対応する」ことなので、
   定式化上そもそも不可能である。多くの実装がこれを「後処理で分裂だけ別扱い」して回避している。
2. **局所的な貪欲判断は取り消せない。** frame k で下した判断が frame k+20 の情報から見て
   明らかに誤りだと分かっても、逐次的な追跡器は戻れない。特に**分裂の誤検出**は、
   「直後に生まれた細胞がすぐ死ぬ／すぐまた分裂する」という**生物学的にありえない寿命**として
   後から発覚することが多い。

### 提案手法の概要

本手法は、既存の軽量な追跡器 **EmbedTrack**（Tracking-by-Regression: 2枚の連続フレームを入力に、
セグメンテーション・重心オフセット・動きオフセットを1つのネットワークで同時回帰する）を
**再学習せず、重みも一切変えずに**そのまま使い、その出力を**確率分布に格上げ**したうえで、
**多重仮説追跡（MHT）** に流し込む。貢献は4点。

#### 1. テスト時シフト拡張による偶然的不確実性（aleatoric uncertainty）の推定

通常のTTA（回転4方向＋反転で8通り）は幾何変換の分散しか測らない。著者らはこれに加えて、
**現フレーム `I_k` は固定したまま、直前フレーム `I_{k-1}` だけを空間的にずらす**という
問題固有の拡張を導入する（4方向 × 既存8通り ＝ 計40通り）。ずらす量は**細胞半径の平均**。

狙いは明快で、「見た目がそっくりな細胞が近くに複数いるとき、回帰ネットワークは
実質的に最近傍マッチングというヒューリスティックをやっているだけではないか」という仮説の検証である。
実際、標準TTAだけでは**曖昧な場面でもネットワークは自信満々**（分散が小さい）。
1ピクセルずらすと少し分散が増え、細胞半径ぶん（4ピクセル）ずらすと、
**再同定が難しい細胞だけ分散が跳ね上がり、明瞭な細胞の分散は小さいまま**になる。
これが欲しかった「曖昧さの検出器」になっている。

得られた画素ごとの分散を、セグメンテーションスコアを重みとするガウス混合として1細胞ぶんに統合し、
検出 j を「点」ではなく**2次元ガウス密度 `N(μ, Σ)`（重心・動きの両方）** として表現する。
あわせて、重心画素のセグメンテーションスコアの補数 `1 − D` を**クラッター確率**（誤検出である確率）として使う。
手作りの定数だった値が、モデルの出力から自然に出てくる形になる。

> ずらす量は重要で、半分だと効果が薄く、倍にすると**確実な細胞の分散まで増えてしまい**性能が落ちる（Table 3）。
> 9データセット中8つで「細胞半径ぶん」が最良だった。

#### 2. 分裂を許すコスト行列（列の複製）

これが最も実装が軽く、最も直接効く貢献である。通常のMHTのコスト行列は

```
C = [ C(j,i) | Diag_∞(c(j,unassigned)) ]
```

という形（左が「検出jを既存物体iに割り当てるコスト」、右が「検出jをどこにも割り当てないコスト」を対角に置いた部分）。
著者らはここに**左ブロックの複製をもう1枚右に足す**だけの変更を加える。

```
C = [ C(j,i) | Diag_∞(c(j,u)) | C'(j,i) = C(j,i) ]
```

複製された列は同じ物体 i を指すので、`j₁` が元の列に、`j₂` が複製列に入れば、
**1対1制約を守ったまま、2つの検出が同じ親に割り当たる** ＝ 分裂が表現できる。
アルゴリズム（ハンガリー法／Murty法）は一切変更しなくてよい。

#### 3. Erlang寿命事前分布による「生物学的にありえない分裂」のペナルティ

複製列だけを足すと分裂が出やすくなりすぎる。そこで著者らは、複製列側にだけ加算される追加コストを置く。

```
c^M(i) = −log ∫[−∞, Age(i)] Erlang_{α,β}(t) dt
```

`Age(i)` は「その細胞が今何フレーム生きているか」、Erlang分布は細胞寿命の分布として
生物学で使われる分布である。この式は**細胞周期の累積分布**であり、
まだ若い細胞ほど積分値が小さく、`−log` が大きく、つまり**分裂コストが高くなる**。
「生まれたばかりの細胞がもう分裂するのは変だ」という知識が、そのままコストになっている。

`α, β` はデータの増殖率から推定できるが、**分裂がまれで推定できない短い系列では `α = K, β = 1/K`
（K は系列長）に設定して一律に高いペナルティにする**、という実務的な逃げ道も明記されている。

#### 4. カルマンフィルタの廃止（暗黙の動きモデル）

MHTは通常カルマンフィルタで次フレーム位置を予測するが、時間ラプス動画の細胞の動きは
ランダムウォークに近く、線形運動モデルが成り立たない。著者らはこれを捨て、
**EmbedTrackが画像から回帰した動きの推定値そのもの**を予測に使う（式10）。
検出に割り当たらなかった物体は、平均位置はそのままで**共分散だけを1フレームぶんの平均移動量だけ膨らませる**
（＝「見失っている間は、居場所の確信が薄れていく」を素直に表現）。

そしてMHTの本領として、frame k で有力だった仮説を frame k+5 の情報で**棄却できる**。
論文の図2の例では、frame 2 で分裂に見えた（実際は過分割）ケースが、
frame 5 で「その細胞の寿命が短すぎる」という矛盾を生み、
**分裂なしの仮説が事後的に勝つ**という流れが示されている。

### 主な結果

評価は Cell Tracking Challenge の9データセット、公式評価サーバ経由。
指標は生物学的指標 **CT**（完全に正しく再構成できたトラックの割合）、**TF**（トラックの連続正解率の平均）、
**BC(i)**（分裂イベントの検出正解率）、**CCA**（予測と正解の細胞周期分布の重なり）、
およびアブレーションで **CHOTA**（各リンクを「追跡結果全体への影響」で重み付けする総合指標）。

| データセット | 指標 | ベースライン(EmbedTrack) | 本手法 | 従来SOTA(Top#1) |
|---|---|---|---|---|
| BF-C2DL-HSC (1763フレーム) | CCA | 12.23 | **69.63** | 56.33 |
| BF-C2DL-HSC | CT | 5.94 | **20.59** | 5.94 |
| BF-C2DL-HSC | BC(i) | 32.46 | **58.82** | 44.05 |
| BF-C2DL-HSC | TF | 62.26 | **79.88** | 62.26 |
| BF-C2DL-MuSC (1375フレーム) | BC(i) | 24.68 | **60.40** | 65.10 |
| DIC-C2DH-HeLa (114フレーム) | CT | 12.20 | **29.19** | 16.88 |

- **9データセット中5つで新SOTA**（生物学的指標）。重みの再学習は**一切していない**。
- 改善は**長く複雑な系列に集中**する。短い系列（そもそも細胞周期が丸ごと入らない）では差が縮む。
- **最重要の観察**: 技術的指標では本手法とベースラインの差は「ほぼノイズ」。
  にもかかわらず生物学的指標では最大**5.7倍**の差がつく。
  **同じ結果を別の指標で測ると、順位が全く違って見える。**

**アブレーション（Table 4, CHOTA）** — 貢献のうち何が効いているか:

| 設定 | BF-C2DL-HSC | BF-C2DL-MuSC |
|---|---|---|
| 全部入り | 76.75 | 82.24 |
| 分裂コスト `c^M = 0` を外す | **48.31** | **68.75** |
| カルマンフィルタに戻す | 69.31 | 32.95 |
| 仮説を1本に制限 `H_max = 1` | 77.30 | 80.38 |
| 割当サンプル1本 `A_max = 1` | 74.78 | 80.85 |

**Erlang寿命コストを外した時の崩壊が最も大きい**（HSCで76.75→48.31）。
つまり本手法の効きの本体は「分裂を許す」ことより「**ありえない分裂を寿命の事前分布で罰する**」ことにある。
複製列だけ足して寿命コストを入れないと、分裂が出すぎて逆効果になる、と読める。

**実行時間（意外な副産物）**: 分裂許容コスト行列は行列サイズが増えるのに、
`c^M = 0`（分裂を許す）設定ではハンガリー法が**むしろ速くなる**。
最適化問題が単純になり、ヒューリスティックな初期解がそのまま最適解になる頻度が上がるためと説明されている。
逆に `c^M = ∞`（分裂を禁止）にすると、走査する要素だけ増えてわずかに遅くなる。
MHT本体の実行時間は `A_max`, `H_max` に対しておおむね線形（i9-9900K, CPU）。

### Kaggleでの実践への示唆（Biohub - Cell Tracking）

#### 実装可能な仮説

**仮説1: ハンガリー法のコスト行列を「列複製」して、割当の段階で分裂を出す**

- **手法**: 現在の2段階ハンガリー法（08-20 の厳格6µm→緩和10µm、08-21 の6.5µm→緩和）のコスト行列に、
  左ブロックの複製 `C'` を右に連結する（式11）。複製列には後述の寿命コストを加算する。
  既存の `scipy.optimize.linear_sum_assignment` はそのまま使える。
  複製列に割り当たった検出を「2人目の娘」としてラベルする。
- **期待インパクト**: 現状 分裂 TP/FP/FN = **0/0/14**（08-20実測）。分裂項が公式スコアに含まれるため、
  ここが 0 から動くこと自体が直接の得点になる。同時に、後処理の `safe divisions` が担っていた仕事が
  割当本体に移るので、`SAFE_DIV_GLOBAL_FRAC_CAP` のような総量規制のチューニングから解放される。
- **工数**: **小**。コスト行列の組み立てと、割当結果のインデックス解釈（`col >= n_obj + n_det` なら複製列）
  の2箇所、実質30〜50行。推論時間は論文の測定によればむしろ**微減**する可能性がある。
- **出典**: 式(11), Figure 3（実行時間）

**仮説2: Erlang寿命事前分布を、`SAFE_DIV_GLOBAL_FRAC_CAP` の原理的な置き換えとして入れる**

- **手法**: 各トラックの現在の生存フレーム数 `Age(i)` を保持し、
  複製列のコストに `−log(ErlangCDF_{α,β}(Age(i)))` を加算する。
  `α, β` は学習データの系統樹から分裂間隔のヒストグラムを取って当てはめる
  （Biohubの学習データには正解の系統樹があるので、これは**その場で計算できる**）。
  推定が不安定なら論文の逃げ道 `α = K, β = 1/K` を使う。
- **期待インパクト**: アブレーションではこれが**効きの本体**（CHOTA 76.75→48.31 の差を生む項）。
  現状の総量規制は「全辺数の一定割合まで」という**細胞ごとの文脈を持たない上限**なので、
  「若い細胞の分裂を高く、成熟した細胞の分裂を安く」する寿命コストのほうが、原理的に筋が良い。
  分裂のFP抑制は 08-21 の `DeepCenter拒否権` と**独立な情報源**（見た目 vs 時間）なので、併用できる。
- **工数**: **小〜中**。Ageの持ち回りが要るのでトラック管理側に手が入るが、
  分布の当てはめは `scipy.stats.erlang.fit` 相当で済む。
- **出典**: 式(12), Table 4

**仮説3: 「直前フレームだけをずらす」TTAで、リンクゲート幅を細胞ごとに可変にする**

- **手法**: 現在のTTAは4方向フリップのロジット平均（08-20）。これに加えて、
  **直前フレームだけを細胞半径ぶん平行移動**した入力での推論を足し、
  検出位置の**ばらつき（分散）**を細胞ごとに測る。
  分散が大きい細胞ほどリンクゲートを広く／リンクコストの信頼度を下げる、という形で使う。
  現状のゲートは 6.0µm / 6.5µm / 10µm の**固定値**なので、ここを可変にする。
- **期待インパクト**: 中。密集領域（再同定が難しく、乗り移りが起きる場所）を
  **モデル自身に申告させる**ことになる。08-20 の `sim2`（検出スコアの急変にペナルティ）と
  同じ問題を狙っているが、より直接的な曖昧さの指標になる。
- **工数**: **中〜大**、かつ**リスクあり**。論文の設定では推論回数が 8 → 40 通りと**5倍**になる。
  Biohubの上位notebookは T4 x2 で17〜23分を使っており、**この枠にそのままは乗らない**。
  現実的には (a) 全40通りではなく「4方向シフトのみ追加」で 8 → 12 通りに留める、
  (b) 分散推定を全フレームでなく密集フレームだけで行う、といった間引きが要る。
  **仮説1・2を先にやるべきで、これは後回し**。
- **出典**: Section 4.1, Table 3

#### 適用にあたっての注意（この論文がそのままは使えない点）

1. **2D vs 3D異方性**。論文の評価は全て2D（CTC）。Biohubは3Dで、しかも
   `VOXEL_SCALE_UM = (1.625, 0.40625, 0.40625)` の**z方向がxyの4倍粗い異方性ボクセル**（08-19 で確認済み）。
   ガウス密度 `Σ` を3Dに拡張する際、**等方ガウスを仮定すると z 方向の不確実性を4分の1に過小評価する**。
   共分散は必ず µm 単位の物理空間で組むこと。これは 08-19 で「3D生物画像で最も踏みやすい罠」として
   既に記録されている落とし穴の、そのまま延長線上にある。
2. **仮説爆発**。論文は `H_max = 150`, `A_max = 7`。Biohubのフレームあたり細胞数と系列長でこれをやると、
   時間・メモリともに厳しい可能性がある。ただしアブレーションを見ると
   `H_max = 1`（＝仮説を1本しか持たない、実質は単なる逐次割当）でも
   **分裂コストさえ入っていれば CHOTA 77.30 と全部入りとほぼ同等**。
   **MHTの仮説管理を実装せず、コスト行列の変更（仮説1・2）だけを既存パイプラインに移植する**のが
   費用対効果として最善で、これが本ダイジェストの結論である。
3. **メトリックハックとの区別**。08-20 で確認した通り、Biohub公開LBの0.95以上の上位群は
   指標実装の脆弱性を突いている疑いが強い。本論文の改善は**指標の穴ではなく分裂という実体**を
   取りに行くものなので、Private LBやコンペ終了後の再評価に対して頑健なはずである。
   逆に言えば、**公開LB上では上位群ほど伸びて見えない**可能性がある点は覚悟しておく。
4. **論文が持ち出す「技術的指標 vs 生物学的指標」の乖離は、Biohubでは部分的にしか成り立たない**。
   Biohubの公式スコアは検出＋リンクJaccard＋分裂の複合であり、
   分裂項を**明示的に含んでいる**（＝CTCの純粋な技術的指標より生物学寄り）。
   なので論文ほど劇的な差にはならない可能性が高い。ただし現状の分裂検出が0件である以上、
