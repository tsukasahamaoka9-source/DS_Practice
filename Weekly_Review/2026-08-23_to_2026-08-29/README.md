## 2. 今週繰り返し登場した手法・パターン Top5

### ① 順位（rank）空間での融合 — 18本中12本、3コンペすべて

今週の背骨。ROC-AUC も macro-AUC も**順序しか見ない**ため、確率のまま平均すると
「分布の広いモデル・自信過剰なモデル」が実力以上に支配してしまう。だから混ぜる前に順位へ写す。
ただし今週の18本は、**同じ道具を使いながら習熟度が3層に分かれていた**。

| 層 | 出典 | 実装 |
|---|---|---|
| **道具を持っているだけ** | 08-26 Playground（0.97128） | `rank01` で 0.45:0.55 に混ぜる。**混ぜた結果が入力の片方と完全に同一スコア**。相関を印字するが判断には使わない |
| **道具の副作用まで見ている** | 08-27 Playground（0.97127） | `(rankdata−0.5)/n` で開区間に収め、重みを 0.725 ではなく **0.725001** にする。0.725=29/40 だと順位和に同点が生じ、AUC上で同点は0.5点扱い＝順序情報の切り捨てになるため。`assert np.unique(pred).size == len(pred)` で機械保証 |
| **混ぜない条件まで実装** | 08-26/08-27 RSNA（0.936） | 相関 > 0.992 なら重み×0.50（似すぎ＝混ぜても無駄）、相関 < 0.65 なら重み×0.40（違いすぎ＝片方が壊れている疑い）。**両側ガード** |

**なぜ効くか**: AUCは単調変換に不変なので、rank化は情報を1ビットも失わない一方で
キャリブレーション差だけを消せる。「損をせずにノイズだけ落とせる」という珍しく無条件に得な変換である。
08-28 の Rank-Gauss（順位 → 一様 → `norm.ppf` で正規分布）は、さらに一歩進めて
**端（確信度の高い領域）の間隔を引き伸ばし、上位での意見の食い違いを重く扱う**変形。

**持ち帰るべき教訓**は、道具そのものではなく第3層の実装である。
08-26 の日次まとめの表現を借りれば——**「rank空間で混ぜる」という道具そのものには価値がなく、
価値があるのは "どこで混ぜるのをやめるか" の判断**。

### ② 調和平均による双方向リンク融合 — Biohub 枠 6日中5日

今週の Biohub 枠でほぼ毎日登場した、正攻法帯（0.917〜0.927）の中核技術。

リンク確率を順方向（t→t+1）と逆方向（t+1→t）の両方で計算し、**調和平均**で統合する。
算術平均は「片方だけ自信あり」を通してしまうが、調和平均は小さい方に強く引きずられるため、
実質的に **AND 条件**になる（F1スコアが精度と再現率の調和平均であるのと同じ論理）。

- 08-23（0.917）: 双方向重み 0.20 → 0.30 に引き上げ。`# REVIEW:` に探索履歴つき
- 08-24（0.923）: 「fixed-90 dual-seed ベースライン（0.913）にモデルレベルの変更を**1つだけ**加える」と宣言し、その1つがこれ
- 08-26（0.927）: 逆方向重み 0.30。週内の最高値
- 08-28（0.927）: harmonic bidirectional fusion + frame-retention guard
- 08-27（0.926）: **これだけ順方向のみ**。日次レビューは「0.927 帯との差はほぼここにある可能性が高く、実装コストは推論をもう1回時間軸反転で回すだけ」と結論している

**なぜ効くか**: 評価指標が Edge Jaccard（重み約0.85）＋ Division Jaccard（約0.15）で、
Jaccard は `|A∩B|/|A∪B|` なので**偽陽性と偽陰性を対称に罰する**。
リンクを採用しすぎるとFPで、落としすぎるとFNで、同じだけ損をする。
その中で「両方向が支持するときだけ採用」は、**採用基準を保守側に倒しつつ、根拠のあるリンクは落とさない**
という指標構造への直接的な適合になっている。

**同時に、今週最大の未解決問題もここにある**。正攻法帯の天井 0.927 と、
上位群 0.965〜0.969（`divaug` を名前に掲げる系統）の間の **0.04 の壁**は6日間まったく動かなかった。
08-25・08-26 の日次レビューが共通して指摘しているとおり、
上位群は分裂サンプルを**増強**（division augmentation）しているのに対し、
今週見た6本はすべて幾何ゲート・4重フィルタ・上限率キャップで分裂を**抑制**する方向に振っている。
「抑制して安全に取る」か「増強して当てにいく」かが、スコア帯を分けている疑いが濃い。

### ③ 静かな失敗（silent failure）を検出する仕組み — 18本中14本

今週いちばん驚いたのは、**上位notebookのコードの約半分が「スコアを上げる機構」ではなく
「正しく動いていることを自分で証明する機構」に費やされている**という事実だった。
3コンペにまたがって、ほぼ同型のパターンが独立に現れている。

| 仕組み | 何を捕まえるか | 出典 |
|---|---|---|
| **Configuration Guard** | 環境変数の実測値と期待値を突き合わせ、1つでもズレたら即例外。56分の推論を間違った設定で走らせる事故を最初の1秒で潰す | Biohub 08-23 / 08-24 / 08-26 / 08-28 |
| **Pipeline Manifest** | 「設定（意図）」ではなく **「条件分岐の解決後の状態（現実）」** を印字。`weights_found=False` なら dual-seed のつもりでも実体は single-seed | Biohub 08-23 / 08-24 / 08-26 / 08-28 |
| **Model Fingerprinting** | 固定シードの乱数入力に対する出力ハッシュを照合。`load_state_dict(strict=False)` が**キー不一致を黙って無視し、一部がランダム初期化のまま推論が「成功」する** 最悪の失敗を捕まえる | RSNA 08-23 / 08-27 |
| **重みファイルの SHA-256 検証** | 外部データセットは所有者が差し替えうる。「昨日と同じモデルを使っている」は確認しない限り保証されない | RSNA 08-24 / 08-27 / 08-28 |
| **提出スキーマの assert** | 多ラベル提出の「列名は合っているが順序が違う」事故。**AUCが0.5付近になるだけで例外は出ない** | RSNA 08-26 / 08-28、Biohub 08-25 / 08-27 |
| **入力の同一性検査** | ブレンド最多の事故「行の並びがずれている」。`frame["id"].equals(sample["id"])` の1行 | Playground 08-27、Biohub 08-25 |
| **フェイルセーフ提出** | 例外時に全0.5の提出／バックアップからの復元。Code Competition では実行失敗＝0点 | RSNA 08-23 / 08-26 / 08-27 / 08-28 |

**共通する設計思想**は一言で言える——**モデルはエラーを出さずに静かに壊れる**。
例外が飛ぶ失敗は自動的に見つかるが、「重みがロードされず初期状態のまま推論した」
「TTAのモンキーパッチが対象文字列に一致せず何もしなかった」「列順が違って予測とIDがずれた」は、
どれも**それらしい数字を返してくる**。08-23 の原著者いわく、
これまで見つかった静かなバグは全部 Pipeline Manifest の1つの印字で見えていたはずだった。

**持ち帰り**: 自分のパイプラインでも、**「設定した値」ではなく「解決後の状態」を1画面に印字するセル**を
標準装備にする価値がある。コストはほぼゼロで、防げる事故の期待値が大きい。
08-25・08-26 が共通して指摘している「`_s.replace(_old,_new)` は失敗しても例外を出さないので
`assert _old in _s` を前に置け」も、同じ発想の最小実装。

### ④ 指標の分解可能性を利用した「所見別・部分適用」最適化 — RSNA 枠 5日すべて

macro-averaged AUC は `Final Score = (1/12) Σ AUC_i` と**12個の独立なAUCの単純平均**である。
この構造は「所見ごとに別々に最適化してよい」ことを数学的に保証する。今週の RSNA 枠は、
この分解可能性をあらゆる粒度で使い倒していた。

- **所見別ブレンド重み**（08-24 / 08-26 / 08-27）: `{"ACL": 0.025, "MCL": 0.16, "Synovitis": 0.16, "Fracture": 0.020, ...}`。
  新コーパスで伸びた所見はほぼ純粋に主モデル、伸びなかった所見でだけ旧モデルを 12〜16% 混ぜる。
  **「どこで自分が強いか」を知ったうえで、弱いところにだけ助けを呼ぶ**
- **効くところにだけ足す**（08-24 / 08-26 / 08-28）: RadImageNet 系統をベーカー嚢腫と骨折の2所見だけ除外（`_RAD_EXCLUDE`）。
  「アンサンブルは常に足す」ではない
- **弱い所見への資源集中**（08-27）: コーパス拡張で伸びたのは Lateral Meniscus +0.071、Fracture +0.057、Lateral OA +0.048 と
  **もともと弱かった所見に集中**。12等分の平均なので、弱い1所見を伸ばすのが最もスコア効率が高い

同じ発想が Biohub にも現れている。08-28 の frame-retention guard は
「アンサンブルが主モデルより検出候補を減らしたフレームだけ、主モデル単独に巻き戻す」——
**全体一括ではなくフレーム単位で安全側に倒す部分適用**であり、粒度は違うが論理は同一。

**持ち帰り**: 指標が「独立な部分スコアの平均」の形をしているなら、
**単一の重み・単一の閾値で全体を裁くのは明確な機会損失**である。逆に指標が分解できない形なら、
部分最適化は正当化されない。まず指標の式を分解可能性の観点で読む、という順序が正しい。

### ⑤ 「混ぜるのをやめる」判断と、改善幅の統計的検証 — 08-25 / 08-26 / 08-27 / 08-28

先週からの継続テーマ「その差は測定できているのか」が、今週は**撤退の意思決定**として現れた。

今週いちばんの学びどころは 08-27 の RSNA notebook のコード内コメントである。

> 45症例のローカル gold set で **+0.010** に見えたアンサンブル効果は、
> 公開LBでは **+0.001** しかなかった。つまり **+0.010 は gold-set のノイズだった**。
> 効果が誤差でコストは3倍（3アーム）なら、1本に絞る。

そして代わりに効いたのは手法ではなく**データ**だった。学習コーパスを 3,155 → 4,349 studies（+37.8%）に拡張して
0.8923 → 0.9054（+0.0131）。しかもこの主張の書き方が重要で、
「平均が上がった」ではなく **「2000回のブートストラップのうち 92.7% で勝利」** と述べている。

同じ規律が週内の各所に散っている。

- **08-26 Playground**: ブレンド後のスコアが**入力の片方と完全に同一**。「相関の高い予測を混ぜても情報は増えない」の教科書的実例
- **08-25 Playground**: 205メンバー＋レジーム交互作用という複雑な機構が、単純な Elite Rank Average に **0.00002 しか勝っていない**。複雑さが正当化されていない
- **08-28 RSNA**: 単一モデル 0.924 に対し4系統フル融合で 0.936。**4本のパイプラインと3つの外部データセットで得た利得は +0.012**。投資対効果を自分で分解していない、という宿題が残る
- **08-27 Playground**: 診断がテスト予測同士の比較にとどまり、正解ラベルを使っていない。原著者が "the kind of diversity that **can** help"（助けになり**得る**）と慎重に書いているのは正確な自己認識

**持ち帰り**: 改善を主張する前に、**同じ設定を2回走らせたときのスコア幅（ノイズフロア）を測る**。
これを持たないまま小さな検証セットの差を追うと、複雑さだけが積み上がる。
08-27 の一行——**「小さい検証セットは、いつでも喜ばしい嘘をついてくれる」**——が今週全体の要約になっている。

## 3. 今週の珍しい・特徴的な手法

### （1）解剖学的整合ゲート `FL·sin(PA) ≥ MT` — 08-25 UMUD

羽状筋の幾何関係（筋束長 × sin(羽状角) ≥ 筋厚）という**ドメイン知識を、損失関数ではなく
ブール値の整合性投票として使い、補正の適用可否を行ごとに切り替える**。
物理法則・解剖学的制約を「学習させる」のではなく「後処理のゲートにする」発想は、
医用・物理系の回帰タスク全般に転用できる。

同じ notebook が示した **「MTに一律 −0.4mm の系統バイアス補正をかけただけで 0.77681 → 0.76794」**
も特筆に値する。指標が tolerance 正規化 MAE である以上、
**系統バイアスの除去がモデルを強くするより費用対効果が高い局面がある**。
一方で「広範なFL補正は 0.82498（大幅悪化）」という**否定的結果まで表に残している**のは、
今週見た18本の中でも最も誠実な記録の取り方だった。

### （2）重み摂動によるタイ消去（0.725 → 0.725001）— 08-27 Playground

ブレンド重みを 0.725 = 29/40 という有理数にすると、順位和が同点になる行が発生する。
AUC上で同点は「0.5点（半分正解）」扱い＝**順序情報の切り捨て**になるため、
末尾に 0.000001 を足して同点を構造的に排除し、`assert np.unique(pred).size == len(pred)` で機械保証する。

**指標の定義を精読していないと絶対に出てこない工夫**であり、
今週見た「AUCは順序しか見ない」という性質の、最も深いところまで降りた利用例。

### （3）`Decimal(prec=60)` + ROUND_HALF_EVEN によるビット単位の再現 — 08-25 UMUD

出力を厳密に再現する必要があるとき、float の2進表現では不可能。
偶数丸め（banker's rounding）は多数行にわたる**丸めバイアスの蓄積**も防ぐ。
Kaggle 特有ではあるが、金融・計測系の実務では普遍的に必要になる知識。

## 5. 今週の論文消化との接続

今週の Paper Digest は **[2026-08-26: US-JEPA — A Joint Embedding Predictive Architecture for Medical Ultrasound](../../Paper_Digest/2026-08-26/)**
（arXiv:2602.19322, UCLA）1本。

**選定はボトルネック起点で、そのボトルネックは 08-25 の UMUD 回から来ている。**
UMUD Challenge の本質的な制約は「ラベル付き超音波画像が少ない」ことであり、
腱膜・筋束のピクセル単位アノテーションは専門家にしか付けられない。
一方で動画から切り出した**ラベルなしフレームは大量にある**（テストが5フレーム連続で切り出されている構造がその証拠）。

US-JEPA の主張は、超音波における自己教師あり学習の主流である masked image modeling（MIM）が
**ピクセル復元パラダイムに縛られているせいで筋が悪い**、というもの。
超音波はスペックルノイズが乗りSN比が低く、装置と術者に強く依存するため、
ピクセル復元を目的にするとモデルは表現能力を
**「その日の装置設定に固有で、意味を持たないノイズの再現」に費やしてしまう**。
JEPA はピクセルではなく**潜在表現**を予測することでこれを回避する。

**今週の Kaggle 実践との接続点は3つある。**

1. **UMUD への直接の処方箋**。08-25 の改善提案「まず DL_Track_US を素直に再現し、CVでベースラインを引く」の
   次の一手として、**ラベルなしフレームでの JEPA 事前学習**が具体的な選択肢になる。
   公開notebookが総崩れしている領域なので、まっとうなパイプライン＋事前学習で公開2位に入れる余地がある。
2. **RSNA Knee の backbone 問題と同型**。08-26・08-27 が繰り返し指摘している
   「DINOv2（自然画像 LVD-142M で事前学習）を、ドメイン内事前学習モデル（OrthoFoundation 系 DINOv3 backbone）に
   差し替えるべき」という提案は、US-JEPA が超音波で主張していることの MRI 版である。
   **事前学習ドメインを変えるほうが、アーキテクチャを変えるより誤りの非相関性が稼げる**——
   これは 08-23 の Playground notebook が「識別モデル × 生成モデル」で言っていたことと同じ論理でもある。
3. **ラベル希少性という共通構造**。RSNA Knee は 4,407件中**構造化ラベルが58件だけ**で、残りは LLM がレポートから作ったソフトラベル。
   UMUD は専門家アノテーションが希少。**今週扱った実コンペ2つとも、本丸は画像モデルではなくラベル（と事前学習）の問題**だった。

## 6. 一言まとめ — 来週意識したいテーマ

今週の18本を貫いていたのは、**「混ぜる技術」ではなく「混ぜた結果を測る技術」**だった。
モーメントマッチング、相関による自動減衰、ブートストラップ勝率、順位シフトの分布、タイの排除——
どれも「効いたかどうかを LB スコア1個で判断しない」ための道具である。

そして、その規律を持たないとどうなるかも、同じ週の中に並んでいた。
S6E8 は6日間の変動幅 0.00009 で団子になり、学習ゼロの notebook が最上位帯に並んだ。
RSNA は公開上位が単一系譜のポートに完全収束した。
**公開LBが情報を持たなくなった領域では、追うべき数字はOOFであって順位ではない。**

**来週意識したい3つ**

1. **Biohub の 0.04 の壁に、抑制ではなく増強で挑む**。6日間で正攻法帯の天井 0.927 に到達したが、
   上位群との差は「分裂を抑制するか増強するか」の設計思想にある疑いが濃い。
   `divaug` 系の分裂サンプル増強を、次に Biohub 枠を選ぶときの読解軸にする。
2. **ノイズフロアを先に測る習慣**。08-27 の「45症例で +0.010 に見えたものが実は +0.001 だった」を、
   自分の実験でも起こる前提で扱う。**同じ設定を2回走らせたときのスコア幅**を出してから改善を主張する。
3. **飽和したコンペからの撤退判断**。S6E8 は 8/31 終了で残り2日。20本以上扱ってきたが、
   限界収穫はほぼゼロになっている。**08-25 の UMUD 切り替えが今週最大の収穫だった**という事実を、
   来週以降の選定方針に反映する——「公開notebookが総崩れしている領域を探す」を明示的な選定基準に加える。
